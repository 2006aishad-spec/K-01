# Segurança e privacidade

Obrigado por ajudares a proteger o K 01.

## Não publiques dados sensíveis

Não abras issues públicas com:
- palavras-passe, tokens, chaves de API ou cookies;
- nomes completos, números de aluno, notas ou boletins identificáveis;
- dados privados de professores ou alunos;
- capturas de ecrã que exponham informação pessoal.

## Como reportar

Para problemas de segurança, contacta primeiro o responsável pelo projeto através dos canais privados disponíveis na conta proprietária do repositório. Inclui uma descrição mínima, os passos para reproduzir e o impacto observado, sem divulgar dados de terceiros.

Não testes nem ataques serviços externos sem autorização explícita.

## Estado

Este repositório ainda não contém uma política formal de resposta a incidentes nem um prazo de correção garantido. Não assumas que a aplicação está certificada para tratar dados escolares sensíveis.
