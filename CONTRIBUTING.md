# Contribuir para o K 01

## Antes de contribuir

- Explica o problema ou melhoria.
- Não incluas dados reais de alunos, tokens, palavras-passe ou chaves.
- Mantém as regras escolares e as fórmulas de avaliação documentadas.
- Não declares uma função como testada sem executar e registar o teste.

## Relatórios de erros

Inclui:
1. versão da aplicação;
2. modelo do dispositivo e versão Android;
3. passos para reproduzir;
4. resultado esperado;
5. resultado observado;
6. capturas de ecrã sem dados pessoais, se forem úteis.

## Alterações ao código

O código-fonte completo ainda precisa de ser disponibilizado neste repositório. Quando estiver presente, descreve as alterações, executa os testes relevantes e atualiza a documentação.
